# Final closed-beta checklist

Owner feedback is the UX acceptance reference. The owner reported that one
external tester launched the M6.3 portable app on another Windows device and its
local Workshop collection was detected, with no blocking error reported. Device
details, Windows version, collection size and later workflows were not provided.
This is encouraging launch/detection evidence, not comprehensive compatibility
testing or a pass for the finalized M6.4 binary.

- Extract the full ZIP to an ordinary user folder; launch without Python/admin.
- Choose the L4D2 root once; verify local detection without changing game files.
- Close/reopen; confirm saved folder opens automatically without another prompt.
- Confirm cached data appears and background Steam info does not block navigation.
- Browse All Mods, search and inspect status/preview failures gracefully.
- Use Category / Target: Survivors → Rochelle; Weapons → Rifles → Desert Rifle;
  select All Weapons or All Mods to return to broader results.
- Open Details; identify Original Target and Replacement / Change immediately.
- Use a suggestion, correct it if necessary, Save Changes. A suggestion is not
  automatically confirmed. More options → Custom catalog name is a separate field.
- Expand/collapse options, navigate/refresh and close with an unsaved draft;
  ensure it is retained or explicitly discarded, never silently lost.
- Check/uncheck Planning members. Read Mod / Conflicts with / Reason for selected
  pairs. Inspect optional paths; metadata-only overlap should not imply danger.
- Close/reopen and confirm edits and Planning membership remain.
- Test offline behavior; valid cached metadata/corrections remain available.
- On a synthetic installation only, move the game folder, verify a recoverable
  message, restore/reselect it and confirm the saved catalog remains intact.
- Report version, Windows build, steps, expected/actual behavior and redacted
  screenshots. Do not include credentials, personal catalog files or real VPKs.

Check only steps actually executed. Record automated, manual and owner/external
observations separately. Owner release acceptance is still required.
